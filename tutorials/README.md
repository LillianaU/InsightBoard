# Tutoriales InsightBoard

Guía paso a paso para construir InsightBoard desde cero, pensada para niños de 10-11 años.

## Orden de construcción

| Capítulo | Tema | Estado |
|----------|------|--------|
| [C1 - Preparación del taller](./c1/README.md) | Instalar herramientas, terminal, `uv` | ✅ |
| [C2 - Encender el taller (Docker)](./c2/README.md) | PostgreSQL, Redis, contenedores | ✅ |
| [C3 - Crear el proyecto Django](./c3/README.md) | `startproject`, apps, settings, migraciones | ✅ |
| [C4 - Armar las piezas (modelos)](./c4/README.md) | DataSource, Event, DailyMetric, SavedReport | ✅ |

## Cómo usar estos tutoriales

1. Lee cada capítulo **en orden**
2. Haz **cada paso exactamente como se indica**
3. Prueba lo que armaste antes de pasar al siguiente capítulo
4. Si algo falla, revisa la sección "Solución de problemas"

## Requisitos previos

- Una computadora con Windows
- Conexión a Internet
- Ganas de aprender (y un poco de paciencia)

## ¿Te trabaste?

- Revisa el capítulo de nuevo, especialmente los pasos numerados
- Asegúrate de tener Docker Desktop corriendo
- Pregunta a un adulto o busca en Google el mensaje de error

¡Disfruta construyendo! 🚀
